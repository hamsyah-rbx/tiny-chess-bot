A chess engine in under 4,096 bytes of Python 3.13 (standard library only): negamax with PVS, quiescence, null-move pruning and a fixed node budget, so every move is deterministic.

## Run it

```sh
MAKEFUN_ENV_URL=http://127.0.0.1:8999 python3 main.py
```
